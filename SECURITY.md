# Security Policy

## Reporting a Vulnerability

Report security issues privately to the repository owner. Do not include unpatched vulnerability details, credentials, personal study data, or private backups in public issue trackers or discussions.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Disclosure should wait until a fix is available.

## Sensitive Material

Updater keys, Windows code-signing certificates, certificate passwords, access tokens, and personal Shihen backups must never be committed. If a credential is accidentally committed, revoke or rotate it immediately; deleting it from the latest revision is not sufficient.
